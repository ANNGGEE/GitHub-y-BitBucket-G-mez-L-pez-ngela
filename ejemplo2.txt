GitHub es una plataforma online que permite almacenar, gestionar y compartir proyectos de programación. Está basada en Git, un sistema de control de versiones que permite registrar los cambios realizados en los archivos de un proyecto, realizar un seguimiento de su evolución y recuperar versiones anteriores cuando sea necesario.

Los repositorios (Repositories) son espacios digitales donde se almacena y organiza todo el contenido de un proyecto, como el código fuente, imágenes, documentos y otros archivos necesarios para su desarrollo.

Existen dos tipos principales de repositorios según su visibilidad:
Públicos (Public): cualquier persona puede acceder al repositorio, consultar sus archivos y visualizar su contenido. Son especialmente útiles para compartir proyectos y colaborar con otros desarrolladores.
Privados (Private): solamente pueden acceder las personas que tengan autorización. Se utilizan cuando se necesita mantener el código y la información del proyecto restringidos.

Además, los repositorios ofrecen diferentes posibilidades:
Organización de archivos: permiten almacenar los archivos en carpetas para mantener el proyecto ordenado.
Archivo README: permite incluir una descripción del proyecto, explicar su funcionamiento y proporcionar instrucciones de instalación o utilización.
Historial de modificaciones: guardan un registro de los cambios realizados mediante commits, permitiendo consultar cómo ha evolucionado el proyecto.
Colaboración: permiten añadir colaboradores y gestionar sus permisos de acceso.
Clonación: permiten descargar una copia del repositorio en un ordenador para trabajar con el proyecto desde un entorno local.
Gestión del proyecto: cada repositorio puede disponer de herramientas adicionales para gestionar tareas, documentar información y realizar un seguimiento del desarrollo.

En definitiva, los repositorios son la base de GitHub, ya que permiten almacenar, organizar, compartir y mantener un seguimiento de todos los elementos que forman parte de un proyecto.

Tanto si se inicia un proyecto desde cero como si se colabora en uno ya existente, GitHub proporciona un conjunto de herramientas y flujos de trabajo que permiten gestionar las distintas fases del ciclo de vida del desarrollo de software (SDLC).
