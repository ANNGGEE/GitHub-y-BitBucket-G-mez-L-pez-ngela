Sobre este proyecto

Esta página web ha sido creada como parte de un ejercicio práctico para aprender a utilizar GitHub y conocer sus principales funcionalidades.

¿Qué podemos encontrar?

  • Crear y gestionar repositorios.
  • Subir y modificar archivos.
  • Realizar commits para guardar cambios.
  • Conocer el funcionamiento de las ramas.
  • Familiarizarme con el control de versiones.
