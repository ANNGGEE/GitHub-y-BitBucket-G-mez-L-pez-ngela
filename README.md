# GitHub-y-BitBucket-G-mez-L-pez-ngela
Repositorio de prueba para explorar y aprender a utilizar las principales funcionalidades y herramientas que ofrece GitHub

## MODIFICACIÓN DE ARCHIVO
Añadimos nuevo contenido y observamos cómo GitHub registra posteriormente estos cambios.

GitHub permite comparar las diferentes versiones de un archivo mediante la herramienta Diff, que muestra de forma visual las modificaciones realizadas. De esta manera, podemos identificar fácilmente qué líneas se han añadido, eliminado o cambiado entre una versión y otra.
